# دليل SEO ونشر Focus Learn

هذا الدليل يشرح ما أُنجز تقنياً لتحسين ظهور المنصة في محركات البحث، وكيف تنشرها،
وماذا تفعل بنفسك لتحتل المراتب الأولى.

---

## 1. ما الذي أصبح جاهزاً في الكود

### صفحات مُخدَّمة من الخادم (الأهم)
لكل درس/اختبار منشور صفحة HTML كاملة يولّدها Django (لا تعتمد على JavaScript)، فيراها
كل عنكبوت بحث ومعاينة مشاركة و AI:
- درس: `/lesson/<slug>/`
- اختبار: `/quiz/<slug>/`
- صفحة فئة (مادة × مستوى): `/lessons/<subject>/<level>/`
- الصفحة الرئيسية العمومية: `/`

كل صفحة تحتوي: عنوان `<title>` فريد، وصف `<meta description>`، رابط قانوني
`canonical`، وسوم `hreflang` تربط النسختين العربية والفرنسية، Open Graph للمشاركة،
وبيانات منظمة JSON-LD (`LearningResource` / `Quiz`) لنتائج غنية في Google.

### روابط واضحة (slugs)
صار لكل درس واختبار `slug` مقروء مشتق من العنوان بدل الرقم (مثل
`/lesson/les-equations-du-second-degre/`)، ويُولَّد تلقائياً عند الإنشاء.

### خريطة الموقع و robots
- `sitemap.xml` يسرد كل الدروس والاختبارات والفئات المنشورة تلقائياً.
- `robots.txt` يسمح بالزحف ويمنع `/api/` و`/django-admin/` ويشير إلى الـ sitemap.

### واجهة React
عناوين وأوصاف ديناميكية لكل صفحة عبر `react-helmet-async`، مع `canonical` يشير
إلى الصفحة المُخدَّمة من الخادم (اضبط `VITE_SEO_BASE` = عنوان الـ backend).

## 2. النشر (Deployment)

### التوصية: Render.com + PostgreSQL + Cloudflare
1. **قاعدة البيانات**: أنشئ PostgreSQL مُدارة (Render/Railway/Supabase).
2. **الخادم**: انشر مجلد `backend/` على Render:
   - ملف `render.yaml` جاهز في جذر المستودع (Blueprint تلقائي).
   - أو يدوياً: Build = `./build.sh`، Start =
     `gunicorn focuslearn.wsgi --workers 3 --bind 0.0.0.0:$PORT`.
3. **متغيرات البيئة المطلوبة** (على الخادم):
   - `DJANGO_DEBUG=0`
   - `DJANGO_SECRET_KEY=<مفتاح عشوائي طويل>`
   - `DATABASE_URL=<من قاعدة البيانات المُدارة>`
   - `DJANGO_ALLOWED_HOSTS=focuslearn.com,www.focuslearn.com`
   - `SITE_URL=https://focuslearn.com` (يُبنى منه الروابط في sitemap/canonical)
   - `FRONTEND_URL=https://focuslearn.com` (وجهة أزرار "افتح الدرس التفاعلي")
   - `CORS_ALLOWED_ORIGINS` و`CSRF_TRUSTED_ORIGINS` = نطاقك
4. **النطاق + HTTPS + السرعة**: ضع Cloudflare أمام الموقع (مجاني) واربط النطاق.
5. **الواجهة React**: ابنها (`npm run build`) وانشر مجلد `dist/` على استضافة ساكنة
   (Cloudflare Pages/Netlify مجاناً)، واضبط `VITE_SEO_BASE` = عنوان الـ backend.

> ملاحذة: تجنّب خطة Render المجانية للخادم لأنها تُطفأ عند الخمول فيتعثّر زحف
> العناكب؛ الخطة الدائمة (~7$/شهر) أفضل لـ SEO.

### الترحيل من SQLite إلى PostgreSQL
الكود يكتشف `DATABASE_URL` تلقائياً وينتقل لـ PostgreSQL دون تعديل. طبّق
الـ migrations على القاعدة الجديدة (`build.sh` يفعل ذلك)، ثم استورد محتواك من
لوحة الأدمن أو عبر `seed`.

## 3. بعد النشر — خطوات تفعلها بنفسك

1. **Google Search Console** (search.google.com/search-console):
   - أضف نطاقك وأثبت الملكية.
   - قدّم `https://<نطاقك>/sitemap.xml`.
   - استعمل "URL Inspection" على درسين للتأكد من الفهرسة.
2. **Bing Webmaster Tools**: نفس الشيء لمحرك Bing (و AI-search المبني عليه).
3. **تحقق من البيانات المنظمة**: أداة Google Rich Results Test على رابط درس.
4. **الأداء**: افحص بـ Lighthouse (SEO + Performance) واختبار Mobile-Friendly.

## 4. استراتيجية المحتوى (لتحتل المراتب الأولى)

التقنية تجعلك **مؤهّلاً** للظهور؛ الترتيب يحتاج محتوىً ملائماً + وقتاً + روابط.

### استهداف كلمات البحث (مثال: امتحانات الولوج)
- أنشئ **دروساً واختبارات بعناوين مطابقة لما يبحث عنه الطلاب** حرفياً:
  "امتحانات ولوج المدارس العليا للتكنولوجيا EST"، "concours ENSA maths"،
  "تصحيح مباراة ENSAM فيزياء 2024"...
- ضع اسم المؤسسة/المباراة في **عنوان الدرس، وأول فقرة، والوسوم**. هذه العناصر
  هي ما يقرؤه Google أولاً.
- صفحات الفئات (`/lessons/<مادة>/<مستوى>/`) تلتقط الاستفسارات العريضة تلقائياً؛
  أضف محتوى كافياً في كل مادة/مستوى لتقويتها.

### بنية المحتوى
- عناوين وصفية دقيقة، فقرة تمهيدية غنية بالكلمات المفتاحية في كل درس.
- ربط داخلي: كل درس مرتبط باختباراته وبدروس المادة/المستوى نفسه (مُنجز تلقائياً
  في الصفحات المُخدَّمة).
- انشر بانتظام؛ كثرة الصفحات الجيدة تزيد فرص الظهور.

### المصداقية (Backlinks) — الأهم للترتيب
- شارك روابط دروسك في مجموعات الطلاب على فيسبوك/واتساب/تيليگرام والمنتديات
  الدراسية المغربية.
- تعاون مع صفحات/حسابات تعليمية لتضع رابطك.
- فكّر في مدوّنة قصيرة للأسئلة المعلوماتية ("كيف تستعد لمباراة X؟") تجذب زواراً
  ثم توجّههم لدروسك.

### القياس والتحسين
- راجع Search Console شهرياً: ما الكلمات التي تجلب زواراً؟ عدّل العناوين والمحتوى
  لتطابقها أكثر.
- الصبر ضروري: تظهر النتائج عادةً بعد أسابيع إلى أشهر من النشر المنتظم.
