# دليل تحويل الدروس والاختبارات إلى JSON (لإعطائه للذكاء الاصطناعي)

انسخ **القسم الأول كاملاً** والصقه للذكاء الاصطناعي مع المحتوى بأي صيغة:
صور، ملفات PDF، مستندات Word، نصوص منسوخة، جداول... الذكاء الاصطناعي يقرأ
المحتوى ويحوّله إلى JSON. الأقسام التالية مرجع لك أنت.

---

## 📋 القسم الأول: التعليمات الجاهزة للنسخ (الصقها للذكاء الاصطناعي)

````
أنت مساعد متخصص في تحويل محتوى تعليمي إلى صيغة JSON دقيقة لمنصة "Focus Learn".
سأعطيك محتوى دروس أو تمارين أو اختبارات بأي صيغة (صور، PDF، ملفات Word،
نصوص، جداول...). اقرأ المحتوى وحوّله إلى JSON حسب القواعد التالية بدقة تامة.

【القيم المسموح بها — لا تخرج عنها أبداً】
- subject (المادة) — استعمل السلَگ فقط: "mathematics" أو "physics" أو "svt"
- level (المستوى) — استعمل السلَگ فقط: "tronc_commun" أو "bac1_sciences" أو "bac_sciences_math"
- language (اللغة): "ar" للعربية أو "fr" للفرنسية
- status (الحالة): "published" للنشر أو "draft" للمسودة
- quiz_type (نوع الاختبار): "lesson" لاختبار درس أو "entrance_exam" لامتحان ولوج

【مخطط الدرس】
{
  "title": "عنوان الدرس",
  "language": "ar",
  "subject": "mathematics",
  "level": "bac_sciences_math",
  "translation_group": "معرّف-اختياري-يربط-النسخة-العربية-بالفرنسية",
  "tags": ["وسم1", "وسم2"],
  "video_url": "https://www.youtube.com/watch?v=XXXX أو null",
  "status": "published",
  "content": {
    "blocks": [
      { "type": "heading", "text": "عنوان فرعي" },
      { "type": "paragraph", "text": "فقرة نصية عادية." },
      { "type": "latex", "text": "ax^2 + bx + c = 0" },
      { "type": "image", "url": "https://...", "caption": "تعليق اختياري" },
      { "type": "video", "url": "https://www.youtube.com/watch?v=XXXX" }
    ]
  }
}

【مخطط الاختبار】
{
  "title": "عنوان الاختبار",
  "language": "ar",
  "quiz_type": "lesson",
  "linked_lesson_title": "عنوان الدرس المرتبط تماماً كما هو، أو احذف هذا السطر",
  "level": "bac_sciences_math",
  "status": "published",
  "questions": [
    {
      "text": "نص السؤال؟",
      "order": 1,
      "choices": [
        { "text": "جواب صحيح", "is_correct": true },
        { "text": "جواب خاطئ", "is_correct": false },
        { "text": "جواب خاطئ", "is_correct": false },
        { "text": "جواب خاطئ", "is_correct": false }
      ]
    }
  ]
}

【قواعد أساسية يجب احترامها】
1. أنواع البلوكات في الدرس محصورة في: heading / paragraph / latex / image / video فقط.
2. بلوك "latex" = معادلة مستقلة تُعرض في سطر خاص. اكتب صيغة LaTeX فقط بدون علامات $.
   مثال صحيح: { "type": "latex", "text": "\\Delta = b^2 - 4ac" }
3. المعادلات داخل النص (فقرة أو عنوان أو سؤال أو جواب) تُحاط بعلامة $ من الجانبين.
   مثال: { "type": "paragraph", "text": "المميز $\\Delta$ يساوي $b^2 - 4ac$." }
4. في LaTeX داخل JSON: الشرطة المائلة الخلفية تُكتب مزدوجة \\ (مثل \\Delta و \\frac و \\sqrt).
5. كل سؤال يجب أن يحتوي على اختيارين على الأقل، وواحد فقط منها is_correct: true.
6. الحقول الإجبارية للدرس: title, language, subject, level, content.
   الحقول الإجبارية للاختبار: title, language, level, questions.
7. لا تخترع مواد أو مستويات جديدة. إن كان المحتوى لا يناسب القيم المتاحة، أخبرني بدل التخمين.
8. أخرج النتيجة كمصفوفة JSON [ ... ] حتى لو كان عنصراً واحداً، وضعها داخل بلوك ```json محاط.
9. ضع الدروس في ملف/مصفوفة، والاختبارات في ملف/مصفوفة منفصلة.
10. لا تضف أي شرح أو نص خارج الـ JSON إلا إذا واجهت غموضاً وسألتني.

ابدأ الآن بتحليل المحتوى الذي سأرسله (بأي صيغة) وأخرج JSON مطابقاً لهذه القواعد.
````

## 📖 القسم الثاني: مرجع القيم (لك أنت)

### المواد (subject)
| السلَگ | بالعربية | بالفرنسية |
|---|---|---|
| `mathematics` | الرياضيات | Mathématiques |
| `physics` | الفيزياء | Physique |
| `svt` | علوم الحياة والأرض | SVT |

### المستويات (level)
| السلَگ | بالعربية | بالفرنسية |
|---|---|---|
| `tronc_commun` | الجذع المشترك | Tronc commun |
| `bac1_sciences` | الأولى باك علوم | 1ère Bac Sciences |
| `bac_sciences_math` | الثانية باك علوم رياضية | 2ème Bac Sciences Maths |

> إذا احتجت مواد أو مستويات إضافية، أضِفها أولاً من لوحة الأدمن (إدارة عبر
> Django admin أو عبر الـ API)، ثم استعمل السلَگ الجديد في ملفات JSON.

### أنواع بلوكات الدرس
| النوع | الحقول | الاستعمال |
|---|---|---|
| `heading` | `text` | عنوان فرعي داخل الدرس |
| `paragraph` | `text` | فقرة نصية (تدعم `$...$` للمعادلات داخل النص) |
| `latex` | `text` | معادلة مستقلة في سطر خاص (بدون `$`) |
| `image` | `url` + `caption` (اختياري) | صورة من رابط خارجي |
| `video` | `url` | فيديو YouTube داخل الدرس |

## 🔗 القسم الثالث: قواعد الربط والاستيراد

1. **الترتيب مهم**: استورد **الدروس أولاً**، ثم **الاختبارات**. لأن الاختبار
   يرتبط بدرسه عن طريق `linked_lesson_title` الذي يجب أن يطابق `title` الدرس
   **حرفياً** ونفس اللغة `language`.
2. إذا كان الاختبار امتحان ولوج عام (غير مرتبط بدرس)، احذف حقل
   `linked_lesson_title` واجعل `quiz_type` = `entrance_exam`.
3. `translation_group`: معرّف نصي حر (مثل `"quad-equations-01"`) تضعه نفسه في
   النسخة العربية والفرنسية لنفس الدرس ليربطهما. اختياري لكنه مفيد.
4. الاستيراد يقبل **عنصراً واحداً `{...}` أو مصفوفة `[...]`** — استعمل المصفوفة دائماً.
5. عند الاستيراد يتحقق النظام من وجود `subject`/`level` ويرجع خطأً واضحاً بالعنصر
   الناقص إن وُجد، فلا خوف من إفساد البيانات.

## ✅ القسم الرابع: مثال كامل مصغّر

### درس (lessons.json)
```json
[
  {
    "title": "المعادلات من الدرجة الثانية",
    "language": "ar",
    "subject": "mathematics",
    "level": "bac_sciences_math",
    "translation_group": "quad-01",
    "tags": ["algebra"],
    "video_url": null,
    "status": "published",
    "content": {
      "blocks": [
        { "type": "heading", "text": "التعريف" },
        { "type": "paragraph", "text": "المعادلة على الشكل $ax^2+bx+c=0$ حيث $a \\neq 0$." },
        { "type": "latex", "text": "\\Delta = b^2 - 4ac" }
      ]
    }
  }
]
```

### اختبار مرتبط (quizzes.json)
```json
[
  {
    "title": "اختبار: المعادلات من الدرجة الثانية",
    "language": "ar",
    "quiz_type": "lesson",
    "linked_lesson_title": "المعادلات من الدرجة الثانية",
    "level": "bac_sciences_math",
    "status": "published",
    "questions": [
      {
        "text": "ما هو مميز $x^2 - 5x + 6 = 0$؟",
        "order": 1,
        "choices": [
          { "text": "$1$", "is_correct": true },
          { "text": "$25$", "is_correct": false },
          { "text": "$-1$", "is_correct": false }
        ]
      }
    ]
  }
]
```

## 💡 نصائح عملية

- راجع الـ JSON الذي يخرجه الذكاء الاصطناعي بصرياً قبل الاستيراد (خصوصاً المعادلات)،
  لأن دقة الاستخراج تتفاوت حسب جودة الملف الأصلي (نص واضح أدق من صورة ممسوحة).
- إن ظهر خطأ عند الاستيراد، تعرض اللوحة رسالة تحدد العنصر والسبب — أصلحه وأعد المحاولة.
- احتفظ بملفاتك في مجلد منظم؛ يمكنك دائماً **تصدير** أي محتوى موجود من اللوحة
  كنموذج JSON صالح لإعادة الاستيراد.
- للمعادلات المعقدة، تحقق أن الشرطة المائلة الخلفية مزدوجة `\\` داخل JSON.
